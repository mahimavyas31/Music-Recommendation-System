# 🎵 Spotify Music Recommendation System

A machine learning-based music recommendation system that uses **Spotify data and audio features** to recommend songs based on user preferences and similarity between tracks.

### 🚀 Features

* 🎧 Personalized song recommendations
* 🎵 Spotify API integration
* 📊 Audio-feature analysis of songs
* 🤖 Machine Learning-based similarity recommendations
* 🌐 Interactive Streamlit web application
* 📈 Data processing and visualization using Pandas, NumPy, and Matplotlib

### 🛠️ Technologies Used

**Python | Pandas | NumPy | Scikit-learn | Spotify API | Streamlit | Matplotlib**

### 💡 How It Works

The system processes Spotify song data and analyzes features such as **danceability, energy, valence, tempo, and acousticness**. It then identifies songs with similar characteristics and generates relevant recommendations for the user.
